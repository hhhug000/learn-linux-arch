# What is Linux?
[<< Previous](README.md) | [Next >>](02-common-commands.md)

Linux is a free and open-source operating system kernel that powers many full operating systems, from servers and desktops to phones and embedded devices. In this module, you will learn what a kernel is, how a Linux distribution is assembled, and why Arch Linux is a popular choice for hands-on learning.

## Kernel vs operating system
The kernel is the core that talks to hardware and manages things like memory, processes, and filesystems. An operating system is the full package you use day to day: the kernel plus userland tools, libraries, services, and a shell or desktop.

A kernel has full control over the system. It is used to manage processes, and facilitate interaction between hardware and software using device drivers.

## Distributions and components
A linux distribution is like a flavour of linux, it has the same base, but changes specific details.

Linux distributions bundle the Linux kernel with userland programs (like GNU tools), a package manager, libraries, and default configurations. The distro decides how these pieces are packaged, updated, and supported.

## Why Arch for learning
Arch keeps things minimal and transparent, so you build your system step by step. That makes it a strong learning environment: you see what each component does and how the system fits together.
