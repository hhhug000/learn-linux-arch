What is the Linux kernel?

<details>
<summary><b>The core that manages hardware and system resources</b></summary>
Correct
The kernel handles low-level tasks like memory, processes, and device drivers. A distro adds userland tools and apps.
</details>

<details>
<summary><b>A desktop environment like GNOME or KDE</b></summary>
Incorrect
Desktop environments run on top of the kernel; they are not the kernel itself.
</details>

<details>
<summary><b>A package manager for installing software</b></summary>
Incorrect
Package managers (like pacman) use the kernel, but they are separate tools.
</details>

<details>
<summary><b>A complete operating system distribution</b></summary>
Incorrect
A distribution includes the kernel plus userland tools, libraries, and software.
</details>
