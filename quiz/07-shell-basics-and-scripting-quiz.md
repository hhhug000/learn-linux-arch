# Shell basics and scripting - Quiz
## Pipes

[Back](../07-shell-basics-and-scripting.md)

What does the pipe symbol `|` do?

<details>
<summary><b>Sends output of one command as input to another</b></summary>
Correct
Pipes connect commands together into a single workflow.
</details>

<details>
<summary><b>Redirects output to a file</b></summary>
Incorrect
Redirection uses `>` or `>>`.
</details>

<details>
<summary><b>Runs a command in the background</b></summary>
Incorrect
Backgrounding uses `&`.
</details>

<details>
<summary><b>Stops a running command</b></summary>
Incorrect
You would use `Ctrl+C` or `kill` to stop a command.
</details>
