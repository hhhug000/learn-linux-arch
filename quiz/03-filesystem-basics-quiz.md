Which statement best describes Linux file extensions?

<details>
<summary><b>They are mostly hints for users, not required by the system</b></summary>
Correct
Linux relies on file content and permissions; extensions are mainly for human readability.
</details>

<details>
<summary><b>They are required for a file to open at all</b></summary>
Incorrect
Files can be used without extensions on Linux; the system does not require them.
</details>

<details>
<summary><b>They always decide which program runs a file</b></summary>
Incorrect
Linux primarily uses file permissions and content, not extensions.
</details>

<details>
<summary><b>They are used only by the kernel to load drivers</b></summary>
Incorrect
The kernel does not rely on file extensions for general file handling.
</details>
