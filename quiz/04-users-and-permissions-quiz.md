What do the permissions `644` mean?

<details>
<summary><b>Owner can read/write; group and others can read</b></summary>
Correct
`6` is rw, `4` is r, so only the owner can write.
</details>

<details>
<summary><b>Owner can read only; group can write</b></summary>
Incorrect
`6` means read and write for the owner, not read only.
</details>

<details>
<summary><b>Everyone can read, write, and execute</b></summary>
Incorrect
That would be `777`, not `644`.
</details>

<details>
<summary><b>Only the owner can read and write; no one else can read</b></summary>
Incorrect
That would be closer to `600`.
</details>
