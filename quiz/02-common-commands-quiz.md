What does `pwd` output?

<details>
<summary><b>Your current working directory path</b></summary>
Correct
`pwd` prints the full path of the directory you are currently in.
</details>

<details>
<summary><b>The name of your current user</b></summary>
Incorrect
That is `whoami`, not `pwd`.
</details>

<details>
<summary><b>A list of files in the current directory</b></summary>
Incorrect
That is `ls`, not `pwd`.
</details>

<details>
<summary><b>The path to your home directory only</b></summary>
Incorrect
`pwd` shows your current directory, which can be anywhere.
</details>
