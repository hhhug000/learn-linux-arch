## Updates

What does `pacman -Syu` do?

<details>
<summary><b>Syncs repositories and updates all packages</b></summary>
Correct
`-S` syncs, `-y` refreshes repo data, and `-u` upgrades.
</details>

<details>
<summary><b>Removes all installed packages</b></summary>
Incorrect
Removal uses `-R`, not `-Syu`.
</details>

<details>
<summary><b>Searches for packages by name</b></summary>
Incorrect
Searching uses `-Ss`.
</details>

<details>
<summary><b>Only updates the kernel</b></summary>
Incorrect
`-Syu` updates all packages, not just the kernel.
</details>
