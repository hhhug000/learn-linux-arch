# Arch installation overview - Quiz
## Archinstall

[Back](../10-arch-installation-overview.md)

What is `archinstall`?

<details>
<summary><b>A guided installer that automates the Arch setup steps</b></summary>
Correct
It walks you through choices and runs the manual steps for you.
</details>

<details>
<summary><b>A desktop environment included with Arch</b></summary>
Incorrect
Desktop environments are separate packages; `archinstall` is an installer tool.
</details>

<details>
<summary><b>A kernel module for hardware detection</b></summary>
Incorrect
It is not a kernel module; it is an installer program.
</details>

<details>
<summary><b>A package manager that replaces pacman</b></summary>
Incorrect
Pacman remains the package manager; `archinstall` only installs the system.
</details>
